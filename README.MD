#Expense tracker

A command-line expense tracker built with Pyhton and SQLite

About:
This project allows users to manage and track their daily expenses.
The application uses SQLite to store expense data and provides several
features for viewing, searching, editing, and deleting expenses.

Features:
- Add new expenses
- View all expenses
- Calculate total expenses
- View expenses by category
- View expenses by date
- View expenses by month
- Search expenses
- View expense summaries
- Edit existing expenses
- Delete expenses
- Input validation
- SQLite database storage

Technologies/Tools
- Python
- SQLite
- SQL
